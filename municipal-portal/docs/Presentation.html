Public Grievance Management System

AI-Powered QA Automation & Engineering Assessment

The Problem

  • Citizens lacked a streamlined, transparent way to report municipal issues (e.g., potholes, broken streetlights).
  • Municipal staff struggled to track, assign, and resolve these grievances efficiently.
  • Lack of clear role separation led to administrative overhead and delayed resolutions.

The Approach

  • Technology Stack: Built a modern web application using Next.js, React, Tailwind CSS, and Prisma (LibSQL/PostgreSQL).
  • Role-Based Access Control: Designed separate portals for Citizens (to submit/track) and Corporation Staff (to manage/resolve).
  • AI-Driven Development: Utilized AI tooling for rapid prototyping, generating automated test scripts, and executing the build-test-fix loop.

The Solution

  • Functional Portal: Live web app deployed on Vercel with seamless user registration and login.
  • Grievance Tracking: Citizens can submit complaints with photo evidence; staff can view assigned tasks and update statuses.
  • Quality Assurance: Comprehensive test suite covering normal paths and edge cases, ensuring robust validation (e.g., preventing empty submissions or role mismatch).
